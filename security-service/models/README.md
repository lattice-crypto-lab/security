# Slow-attack approximation model

The reviewed phase 4 artifact is stored here as `slow-attacks-v1.json` after
Linux/Sage collection and holdout review. The security service does not invent
fallback coefficients: when the file is absent, out of provenance, or outside
its calibrated domain, deterministic applicability rules still exclude clearly
irrelevant attacks, while borderline and applicable attacks fall back to real
estimator execution in normal mode.
